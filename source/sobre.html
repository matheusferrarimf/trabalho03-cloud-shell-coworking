Sobre o cenário

O projeto simula a operação de uma aplicação simples para um pequeno coworking. O ambiente utiliza Docker com Ubuntu, Apache para publicação do site estático e scripts Shell para rotinas de atualização, estruturação de diretórios, backup, deploy, monitoramento, processos, permissões e relatório operacional.

A proposta relaciona o tema de coworking com atividades comuns de DevOps em cloud, como automação, padronização, logs e validação de serviços.
